Effem is a polyphonic synthesizer written in [Faust](https://github.com/grame-cncm/faust).. It features a dual-oscillator FM/AM architecture, an additional noise channel, a pitch-envelope module ("bubble"), a resonant low-pass filter with LFO modulation, overdrive, and a custom feedback reverb algorithm ("Viverb").

## Features

- Polyphony: 16-voice polyphonic engine with MIDI support.
- Oscillators: Carrier/modulator FM/AM pairing alongside an adjustable noise channel.
- Bubble Oscillator: Pitch-envelope generator with selectable waveforms (Sine, Triangle, Square, Sawtooth).
- Effects Chain: Subtractive filter, waveshaping drive, and custom feedback reverb.
